## Projetos

**[Rituno](https://github.com/MarcoCorreaz/Rituno)**
App de hábitos e rotina para quem estuda e trabalha ao mesmo tempo. React + Vite no front, Supabase como back-end, assinaturas via Asaas, e-mails com Resend, monitoramento com Sentry e analytics com PostHog.
`React` `TypeScript` `Vite` `Tailwind` `Supabase`

**[BookReads](https://github.com/MarcoCorreaz/bookreads)** · [demo](https://bookreads-gilt.vercel.app)
Rede social de leitura mobile-first, misturando o check-in do BeReal com o acompanhamento de leitura do Goodreads. Next.js + Supabase no core, com um serviço em Spring Boot fazendo proxy da API do Google Books.
`Next.js` `TypeScript` `Supabase` `Spring Boot` `Stripe`

**[ROUME](https://github.com/MarcoCorreaz/Roume)**
Projeto acadêmico que automatiza a triagem de chamados de manutenção em imóveis pelo WhatsApp, usando IA via n8n.
`n8n` `WhatsApp API` `IA`
