### Projetos

**📚 [BookReads](https://github.com/MarcoCorreaz/bookreads)** — [demo](https://bookreads-gilt.vercel.app)
Rede social de leitura mobile-first ("BeReal encontra Goodreads"), com check-ins fotográficos, streaks e gamificação. Back-end em Next.js + Supabase (Postgres, Auth, Realtime, Storage), com um serviço complementar em Spring Boot fazendo proxy da Google Books API. Documentação de arquitetura e especificação funcional completas no repositório.
`Next.js` `TypeScript` `Supabase` `Spring Boot` `Stripe`

**🏠 [ROUME](https://github.com/MarcoCorreaz/Roume)**
SaaS de PropTech acadêmico que automatiza a triagem de chamados de manutenção imobiliária via WhatsApp com IA, eliminando o atendimento manual. Projeto em equipe (com orientação acadêmica), com foco em automação de fluxo via n8n.
`n8n` `WhatsApp API` `IA`

**📅 [Diurno](https://github.com/MarcoCorreaz/Diurno)** *(ex-Rotina Inteligente)*
App de organização de rotina para estudantes-trabalhadores, com sugestões de IA (Gemini) e persistência em Firebase (Auth + Firestore). Back-end em Java rodando junto a um front-end em React/Vite.
`Java` `Spring Boot` `React` `Firebase` `Gemini API`
