## 🚀 Projetos

### [Rituno](https://github.com/MarcoCorreaz/Rituno) · [site](https://rituno.vercel.app/)
App de hábitos e rotina para quem estuda e trabalha ao mesmo tempo. Estou validando como projeto gratuito antes de transformá-lo em negócio.
**Stack:** React · Vite · TypeScript · Tailwind · Supabase · Asaas (assinaturas) · Resend (e-mails) · Sentry · PostHog

### [BookReads](https://github.com/MarcoCorreaz/bookreads) · [demo](https://bookreads-gilt.vercel.app)
Rede social de leitura mobile-first: o check-in do BeReal com o acompanhamento de leitura do Goodreads.
**Stack:** Next.js · React · TypeScript · Supabase · Stripe · serviço em **Spring Boot** que faz proxy da API do Google Books

### [ROUME](https://github.com/MarcoCorreaz/Roume)
Projeto acadêmico que automatiza a triagem de chamados de manutenção em imóveis pelo WhatsApp, usando IA.
**Stack:** n8n · WhatsApp API · Gemini
