## Projetos
 
**[BookReads](https://github.com/MarcoCorreaz/bookreads)** ([demo](https://bookreads-gilt.vercel.app))
Rede social de leitura mobile-first, misturando o formato de check-in do BeReal com a lógica de acompanhamento de leitura do Goodreads. Front-end em Next.js, Supabase para auth/banco/storage/realtime, e um serviço à parte em Spring Boot que faz proxy da API do Google Books. Tem arquitetura e requisitos documentados no próprio repo, então dá pra entender o projeto sem precisar rodar nada.
`Next.js` · `TypeScript` · `Supabase` · `Spring Boot` · `Stripe`
 
**[ROUME](https://github.com/MarcoCorreaz/Roume)**
Projeto acadêmico (com orientação de professor) que ataca um problema bem específico: a triagem manual de chamados de manutenção em imóveis. A ideia é automatizar esse primeiro atendimento pelo WhatsApp usando IA, via n8n, para tirar trabalho repetitivo de quem administra os imóveis.
`n8n` · `WhatsApp API` · `IA`
 
**[Diurno](https://github.com/MarcoCorreaz/Diurno)**
App de organização de rotina voltado pra quem estuda e trabalha ao mesmo tempo — sugestões de IA (Gemini) para ajudar a montar o dia. Back-end em Java, front em React/Vite, dados e autenticação no Firebase.
`Java` · `Spring Boot` · `React` · `Firebase` · `Gemini API`
